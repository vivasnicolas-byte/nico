Matrices - Tablero de Ajedrez

Este proyecto fue desarrollado utilizando Python y matrices.

El objetivo principal del proyecto era crear un tablero de ajedrez utilizando estructuras matriciales y posiciones organizadas.

El programa muestra piezas dentro del tablero y permite organizar filas y columnas utilizando lógica computacional.

Tecnologías utilizadas:

  • Python
  • Matrices
  • Variables
  • Estructuras de datos

Con este proyecto pude mejorar mis habilidades en lógica computacional y organización de datos.
